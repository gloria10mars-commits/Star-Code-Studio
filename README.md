# Star Code Studio

Studio de clonage de portails de ressources éducatives.

## Lancer en local

**Prérequis :** Node.js

```bash
npm install
```

Optionnel — clé Gemini pour l'assistant :

```
# .env.local
GEMINI_API_KEY=votre_clé
```

```bash
npm run dev
```

Ouvre http://localhost:3000

## Build

```bash
npm run build
npm run preview
```
